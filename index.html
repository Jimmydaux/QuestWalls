Wall Sketch

Press START AR at the bottom. Your layout saves automatically and comes back in the same spot next time.

Modes (left trigger switches)

  • Walls: corners on the floor become walls
  • Furniture: corners become a solid block (3 corners + A makes a rectangle)
  • Items: drop in ready-made furniture (sofa, bed, table…)
  • Anchor A/B: mark two real landmarks to keep the layout lined up with the room

Right controller

  • Trigger: place a corner / item / anchor point
  • Grip: finish the shape · A: close the shape
  • B: undo (in Anchor mode: clear A/B)
  • Stick ↔: rotate item · Stick ↕: next/previous item
  • Stick click with the controller touching the floor: set the floor height

Left controller

  • Trigger: next mode · X: next color · Y: snap on/off
  • Stick ↕: height · Stick ↔: opacity · Stick click: dimensions
  • Hold grip 2s: clear all shapes

Keeping it lined up

The layout is pinned to your room with a spatial anchor. For extra safety, in Anchor A/B mode mark two landmarks you can find again (for example, two room corners). If the layout ever looks shifted, mark A and B again at the same spots and everything snaps back into place.

Editing

Height, color, and opacity change the shape you're drawing. When you're not drawing, they change the last finished shape (outlined in yellow).
